# Smart Grid Project

An interactive demo showing how a city's electricity network responds to power-line failures and restores power.

## How to use

Open a terminal in the project folder and run:

```sh
./run_dashboard.sh
```

Open the address shown in the terminal in your browser (usually `http://127.0.0.1:8000`).

- Click **Guided demo** for a step-by-step walkthrough.
- Choose a scenario, or click a line on the map to simulate a failure.
- Set the hour and click **Run engine** to see the result.
- Use the stage tabs, **Compare policies**, and **Batteries** to explore the results.

Press **Ctrl+C** in the terminal to stop the app.
